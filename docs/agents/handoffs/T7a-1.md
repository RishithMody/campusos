Compose covers dependency services only, not backend/frontend deployment. No public
HTTP deployment, UI escalation, full T2–T5 regression, or live vLLM; those remain T7.

are entirely blocked. No Discord credentials inspected or used.

The signed human-kind test confirms the existing trust boundary: agent-kind fails,
a trusted issuer's human-kind token succeeds even without a real ceremony. The
issuer must enforce human identity/consent; the API does not prove that ceremony.
Same-size audience substitution remains the known frozen-contract gap.

Redis recovery is reconnecting a new stream after a terminal error. Eviction
pressure and a paused-but-connected dependency timeout were not measured. The
inference timeout is injected, not measured from a running model. The fixture
plugin uses pytest fixture internals to substitute both legacy local fixtures;
reverify it on pytest upgrades. No xdist/shared-instance destructive runs supported.
Most fixtures create tables from metadata; Alembic evidence is the existing real
PostgreSQL migration/concurrency test, not every fixture setup.
