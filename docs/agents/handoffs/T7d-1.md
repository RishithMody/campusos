## 1. Completed work

The three code blockers between CampusOS and live Discord verification.

**B1 — nothing could issue a `kind=bot` JWT.** `manage.py` had `provision` and `link-discord`
only, so the credential every channel call requires could not be created at all. Added
`issue-bot`:

```sh
python -m backend.manage issue-bot <subject> --guild <snowflake> [--ttl <hours>]
```

Guild-bound, `kind=bot`, printed once, persisted nowhere, lifetime capped at 24 hours. It
refuses a subject that is already a provisioned student — `Service.student()` would refuse
that credential anyway, but one subject meaning two principals is how such a check eventually
gets reasoned away.

**P1 — `audience()` returned 0 for an empty member page.** Found by T7c. `context()` has
already proved the bot is a guild member who can view the room, so an audience that does not
contain the bot means the enumeration was incomplete. The fix asserts exactly that.

It deliberately does **not** reject empty pages: an empty page is legitimate immediately after
a full one, and `test_an_exactly_full_first_page_still_paginates_to_an_empty_second` pins that
boundary so the fix cannot regress pagination.

Why it matters: `channel_summary` re-asks for consent only when the audience **grew**. An
undercount can never close that gate, so it is the dangerous direction.

**P2 — a non-object body escaped as `AttributeError`.** Found by T7c. A 200 whose body was not
an object reached `room.get(...)` and raised out of the fail-closed envelope, surfacing as a
500. Single-document fetches now go through `document()`, which requires a dict. The bot's own
id is also validated before being interpolated into a request path.

## 5. Known limitations

- **Server Members Intent is unverified and unverifiable from here.** It is a Developer Portal
  toggle, and `guilds/{id}/members` — the only way the backend can count a real audience —
  requires it. The owner's setup notes list OAuth scopes and channel permissions but do not
  mention it. **This is the top remaining blocker for live testing.**
- **Docker startup unverified.** Native processes are not container evidence.
- **No Discord traffic has ever left this machine.** Every Discord behaviour here is
  `httpx.MockTransport`. If Discord's real overwrite semantics differ from `can_view`, these
  tests and that code are wrong together — still the highest-risk unknown, and still T7b's job.
- **12-hour token lifetime.** The minted credential expires; re-mint with the **same subject**,
  because `channel.bot` is pinned at registration and a new subject orphans registered channels.
