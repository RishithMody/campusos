## Objective

Build the FastAPI backend that lets several students' personal agents negotiate on their behalf:
the agent-to-agent protocol, the LangGraph negotiation workflow, durable and ephemeral state, and
the authorization layer that keeps one student's private data out of another's negotiation.

The whole service must run **with no GPU**, against a mock inference client. Phase 1 of the
project is three agents negotiating on mocks; the demo cannot be hostage to the cluster.

### The disclosure ladder — the specification your privacy tests are written against

| Level | May contain | May never contain |
|---|---|---|
| `none` | a yes/no on one proposed time | any enumeration of busy times |
| `free_busy` | intervals busy / free / tentative | reason, category, label, location, participants |
| `category` | `free_busy` + `academic` \| `work` \| `social` \| `personal` | free text of any kind |
| `full` | `category` + a human-readable label | — needs an explicit, logged, scoped grant |

`"busy 2-4pm"` is permitted at `free_busy`. `"therapy at 2pm"` is only ever possible at `full`.
Default for a new negotiation is `free_busy`. Implement the enum exactly; do not reinterpret it.

**The category enum is deliberately blunt.** `personal` absorbs health, therapy and family. Never
add `medical`, `health` or similar — a category that reveals *why* someone is busy defeats the
ladder. **Reasons are a closed vocabulary** (`reason_code`), never prose: free-text explanation
is the most common way a careful system leaks.

### Decisions already made that you must not relitigate

- **Disclosure is enforced server-side, on egress, in one place** (the privacy service). Not in
  agents, not in clients. A client bug must not become a privacy breach.
- **Identity comes from the validated token, never from a client-supplied id**, on every path.
- **Cross-student reads need an explicit grant row and write an audit record.** No implicit sharing.
- **`student_ref` is a per-negotiation pseudonym**, never a name, email or stable id.
- **No MCP anywhere.** Cubbie's sandbox does not support it. The Skill boundary is HTTPS/443.
- **Agent-to-agent traffic never routes through Cubbie** — Cubbie texts only its own student.
- **The negotiation loop is bounded** (`max_rounds`, ceiling 20). Failure to converge is a
  product outcome that escalates to a human, not an error to retry away.
- **Contracts are frozen.** Need a change? Write it in your handoff, set `REVIEW`, and stop.

### Specific to T2

- Build **mock-first**. Phase 1 is three agents negotiating with **no GPU**. Select the client
  with `CAMPUSOS_INFERENCE_MODE=mock|vllm` and **no default**; unset or unrecognised is a startup error,
  never a silent fallback.
- `POST /negotiations/{id}/messages` must reject a malformed envelope with a structured `400`,
  an out-of-scope or expired-scope message with `403`, and an over-disclosing payload with `422`
  — **never a 500, and never by silently redacting.** A loud failure in tests beats a quiet leak.
- `payload.note_for_own_student` is shown only to the student the sending agent represents.
  **Strip it on egress** to any other student's agent.
- Redis holds ephemeral negotiation scratch state with a TTL. Raw `commitment` rows never go in.
- The privacy test must assert on the **actual outbound payload**, not an internal variable.
