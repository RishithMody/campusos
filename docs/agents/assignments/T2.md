## Objective

Build the FastAPI backend that lets several students' personal agents negotiate on their behalf:
the agent-to-agent protocol, the LangGraph negotiation workflow, durable and ephemeral state, and
the authorization layer that keeps one student's private data out of another's negotiation.

The whole service must run **with no GPU**, against a mock inference client. Phase 1 of the
project is three agents negotiating on mocks; the demo cannot be hostage to the cluster.

## File ownership

**Read-only:** `contracts/` — if you need a change, write it in your handoff, set `REVIEW`, stop
**Never touch:** `frontend/`, `ml/`, `infra/`, and every protected file listed in `CLAUDE.md`

## Acceptance criteria

- [ ] FastAPI app starts clean; `GET /health` returns 200
- [ ] Every endpoint in `contracts/api.openapi.yaml` implemented; responses contract-valid
- [ ] Agent-to-agent protocol implemented per `contracts/agent-protocol.schema.json`;
      malformed envelopes rejected with a structured error, never a 500
- [ ] LangGraph negotiation workflow: reaches convergence on a three-student conflict, and
      **escalates to human approval when it cannot** (failure to converge is a product
      feature, not a bug)
- [ ] Negotiation state serialises to `contracts/negotiation-state.schema.json` so T5 can render it
- [ ] PostgreSQL models + Alembic migrations apply cleanly from an empty database
- [ ] Redis for ephemeral session state and pub/sub; no private data persisted past its TTL
- [ ] Every endpoint authenticated; **identity derived from the validated token, never from a
      client-supplied user ID** anywhere
- [ ] Cross-student data access requires an explicit grant row **and** writes an audit record
- [ ] Inference behind an injectable interface with a working mock; no GPU dependency,
      no hardcoded inference URL
- [ ] `ruff` and `mypy` clean
- [ ] `.env.example` committed; no secrets in Git

## Required tests

- [ ] `pytest tests/backend/` green
- [ ] **Authorization:** student A's agent cannot read student B's calendar — tested three ways:
      direct call, forged/substituted user ID, IDOR on a path parameter
- [ ] **Privacy:** a negotiation message carries only the minimum disclosure its level permits
      (asserts on the actual outbound payload, not on an internal variable)
- [ ] **Contract:** responses validate against `contracts/`
- [ ] **State machine:** every negotiation transition, including the no-convergence path
- [ ] Failure paths: inference client unavailable, DB unavailable, Redis unavailable
