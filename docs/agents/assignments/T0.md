## Objective

Replace every assumption about the Cubbie Hackathon with a verified, cited fact. Right now
**this repository contains no verified hackathon rule whatsoever.** The task graph names a
mandatory Cubbie Skill submission because it was identified as one, but its format, scope, and
deadline are unknown here. Every downstream deliverable is shaped by rules nobody has read.
This is a few hours of reading that can save days of building the wrong artifact.

**Read-only:** everything else
