## 🔴 Execution gate

**Writing** scripts, configs, and Dockerfiles requires no approval — do that freely.
**Running** anything against the H200s requires a human-signed approval token in the table
above. With `NONE` there, you do not connect to the cluster, do not deploy, and do not
benchmark. Write it, show the human the exact command, and wait.

Read `docs/infra-policy.md` in full before any remote action. It is binding on this role more
than any other.

## Objective

Serve Qwen3 8B on the H200s behind an OpenAI-compatible endpoint that implements
`contracts/inference.md`, so the backend's mock client can be swapped for real inference with
no code change. Make it reproducible from committed config, safe to restart, private, and
measured.

## Acceptance criteria

- [ ] `infra/validate_env.sh` — **read-only** report: driver version, CUDA runtime, PyTorch,
      vLLM, `nvidia-smi` topology, NVLink/P2P, VRAM per GPU, and **existing GPU processes**.
      Idempotent; mutates nothing; safe to re-run.
- [ ] Documented, working compatibility matrix (driver ↔ CUDA ↔ PyTorch ↔ vLLM) for these H200s.
      Version skew here is the most common way a hackathon loses a day.
- [ ] vLLM serves Qwen3 8B with an OpenAI-compatible API, from **committed config** under
      `infra/`, not ad-hoc shell flags
- [ ] **`max_num_seqs` ≤ 256.** `512` has caused GPU wedging on this hardware and is forbidden.
- [ ] `--gpu-memory-utilization` set explicitly with headroom; tensor-parallel size explicit
- [ ] **Graceful teardown verified:** stop and restart leaves no wedged GPU and no orphaned
      process. A killed vLLM that wedges a GPU costs more time than stopping cleanly.
- [ ] Endpoint bound to **localhost or a private interface only**, reached via SSH tunnel,
      with authentication in front. Never `0.0.0.0` on a routable interface, never a public tunnel.
- [ ] Dockerfiles build; **mock-mode `docker compose up` works on a laptop with no GPU**
- [ ] `infra/benchmarks/` records tokens/sec, time-to-first-token, p50/p95/p99 latency under
      concurrency, VRAM headroom, GPU utilization — **each with the exact command that produced it**
- [ ] No SSH keys, credentials, `.pem` files, or hostnames-with-secrets in Git; host comes from
      an environment variable or parameter with no default

## Required tests
